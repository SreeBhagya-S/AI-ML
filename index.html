Where would you draw the line?

An interactive introduction to Support Vector Machines: separating hyperplanes, the maximum margin, support vectors and kernels. Every figure on this page can be dragged, tapped or adjusted.

Based on the lecture by Sree S Bhagya, Centre for Artificial Intelligence, TKM College of Engineering.

Two classes of points, class +1 and class −1, and many lines that separate them perfectly. Every one of those lines gets the training data right. So which one should we trust for new points?

A line that passes very close to a point is fragile: a new point that lands just a little off will end up on the wrong side. The Support Vector Machine answer is simple: choose the line that stays as far as possible from both classes. The rest of this lesson turns that idea into mathematics.

1What an SVM is

A Support Vector Machine (SVM) is a supervised learning method that classifies data by finding the hyperplane that separates the classes with the maximum margin.

It is supervised because it learns from labelled examples (xᵢ, yᵢ) with yᵢ ∈ {+1, −1}. It is margin-based because it chooses the widest gap between the classes, not just any separator. And it handles both straight and curved boundaries: straight ones directly, curved ones through kernel functions.

SVM is mainly a two-class (binary) method. For more classes, it is run several times. One-vs-Rest trains one SVM per class (A vs not-A, B vs not-B, C vs not-C) and picks the class with the strongest score. One-vs-One trains one SVM per pair (A vs B, A vs C, B vs C) and picks the class with the most votes.

2The hyperplane

A hyperplane is a flat boundary that divides a space into two parts. In n dimensions it has n − 1 dimensions: a line in 2-D, a plane in 3-D, a 3-D flat boundary inside 4-D space. SVM writes it as

w · x + b = 0

The weight vector w is perpendicular to the hyperplane and sets its direction. The bias b shifts it away from the origin. To classify a point, compute f(x) = w · x + b and look at its sign: f(x) > 0 means class +1, f(x) < 0 means class −1. The size of f(x) grows with distance from the line.

With the lecture example w = (1, 1) and b = −4, the line is x₁ + x₂ = 4. Point A (3, 2) gives f = 3 + 2 − 4 = +1, class +1. Point B (1, 1) gives f = 1 + 1 − 4 = −2, class −1. Try changing the sliders and notice that w always points toward the positive side.

3Margin and support vectors

Draw two lines parallel to the hyperplane, one through the nearest point of each class. SVM scales w and b so that these lines are

w · x + b = +1   and   w · x + b = −1

The gap between them is the margin, and its width is

margin = 2 / ‖w‖

The points lying exactly on those two lines, where yᵢ(w · xᵢ + b) = 1, are the support vectors. They are the closest, hardest cases, and they alone hold the boundary in place.

Try these two experiments. First, drag a point that is not circled, as long as it stays outside the band: the boundary does not move at all. Then drag a circled support vector: the boundary follows it. That is why the method is named after these points. Mathematically, w = Σ αᵢ yᵢ xᵢ, and αᵢ > 0 only for support vectors, so every other point contributes nothing.

The optimal separating hyperplane

Of all the separating hyperplanes, the optimal one is the one with the widest margin. That is why SVM is called a maximum-margin classifier: the margin is not a by-product, it is the thing being optimised. Maximising 2/‖w‖ is the same as making ‖w‖ small, so SVM solves

minimise ½‖w‖²subject to yᵢ(w · xᵢ + b) ≥ 1 for every training point

This is a convex problem, so there is one global best answer. It is the most tolerant of noise near the boundary, it tends to generalise better to unseen data, and it depends only on the support vectors.

Why minimise ½‖w‖² rather than ‖w‖?

‖w‖ = √(w₁² + w₂² + … + wₙ²). The square root makes differentiation messy: its derivative brings in an extra 1/(2‖w‖) term. Squaring removes the root and leaves a clean polynomial, ‖w‖² = w₁² + … + wₙ², that reaches its minimum at exactly the same w. The ½ is only there to cancel the 2 that appears when you differentiate.

5Soft margin: real data overlaps

Real data is rarely perfectly separable. The soft margin lets some points sit inside the margin, or even on the wrong side, by giving each point a slack value ξᵢ that measures how much it violates the margin. The objective becomes

minimise ½‖w‖² + C Σ ξᵢ

C sets how strongly violations are punished. A large C makes violations expensive: narrow margin, few training errors, and a risk of overfitting to noise. A small C makes them cheap: wider margin, a few training errors, and usually better generalisation. In practice C is chosen by cross-validation.

The version with no violations allowed is called the hard margin; it only works for perfectly separable data. The soft margin is what is used in practice.

6When no straight line works

Sometimes the classes are arranged so that no straight line can separate them. The idea behind kernels is surprisingly simple: move the data into a higher-dimensional space where a straight hyperplane does separate it.

A one-dimensional example

On a single axis, points sit at both ends and points in the middle. No single cut point separates them. Now give every point a second coordinate, its square: φ(x) = (x, x²).

After lifting, the straight line x² = 4 splits the classes. Back on the original axis, that straight line corresponds to the non-linear rule |x| < 2.

The same idea in two dimensions

Here class +1 sits inside a ring of class −1. The true boundary is a circle. Add a third feature z = x₁² + x₂²: inner points get a small z, ring points a large z, and a flat plane z = constant separates them.

7The kernel trick

Lifting data works, but computing φ(x) for every point can be expensive, and for some mappings impossible, because the new space can be enormous or even infinite-dimensional. Here is the key observation: SVM's training and prediction only ever use dot products between points. So all we need is a function that returns the dot product in the lifted space directly:

K(xᵢ, xⱼ) = φ(xᵢ) · φ(xⱼ)

That function is a kernel. Replacing every x · z with K(x, z) is the kernel trick. Check it yourself with K(x, z) = (x · z)², whose hidden mapping is φ(x) = (x₁², √2·x₁x₂, x₂²).

Four kernels you should know

KernelFormulaUse when
LinearK(x, z) = x · zData is (nearly) linearly separable; many features, e.g. text
PolynomialK(x, z) = (x · z + c)ᵈCurved boundaries of degree d; feature interactions
RBF (Gaussian)K(x, z) = exp(−γ‖x − z‖²)Default choice; circular or irregular boundaries
SigmoidK(x, z) = tanh(κ x · z + c)Behaves like a simple neural network

The parameters γ, c, d and κ are chosen by the user, usually by cross-validation. A valid kernel must satisfy Mercer's condition: the matrix of its values must be symmetric and positive semi-definite. A kernel is also a similarity measure: the RBF kernel gives 1 for identical points and close to 0 for distant ones.

8Kernel playground

Now put it together. This panel trains a real SVM in your browser. It starts on the ring data with a linear kernel, and the accuracy shows it cannot work. Switch to RBF or Polynomial and watch a curved boundary appear, even though the algorithm is still drawing a straight hyperplane in the hidden lifted space.

Things to try: on the ring, a polynomial of degree 2 is enough, because the true boundary is a circle. With RBF, a very large γ makes each point's influence tiny and the boundary wraps tightly around individual points (overfitting); a small γ gives a smooth, almost linear boundary. XOR has no straight-line solution at all, yet RBF handles it easily.

Kernels make four things possible: non-linear boundaries from a linear algorithm; cheap computation, because φ(x) is never built; flexibility, since special kernels exist for text, strings and graphs; and the same convex optimisation, so a single global optimum is still found.

9How SVM works, end to end

  1. Input dataLabelled pairs (xᵢ, yᵢ), yᵢ ∈ {+1, −1}
  2. Choose kernel and CLinear, polynomial, RBF…
  3. Maximise the marginSolve the optimisation for the αᵢ
  4. Find support vectorsPoints with αᵢ > 0 give w and b
  5. ClassifyFor a new x, take the sign of f(x)
f(x) = sign( Σ αᵢ yᵢ K(xᵢ, x) + b )The sum runs over support vectors only. With a linear kernel it reduces to sign(w · x + b).

Where SVM shines, and where it struggles

Advantages

  • Works well in high dimensions, even when features outnumber samples.
  • Memory efficient: only the support vectors are stored and used.
  • Versatile: kernels handle linear and non-linear boundaries.
  • Resists overfitting: the maximum margin and C control complexity.
  • Convex problem: one global optimum, no local minima.

Limitations

  • Slow to train on very large datasets.
  • The kernel and C must be tuned.
  • No direct probability output.
  • Needs feature scaling.
  • Weaker when classes overlap heavily.

11Summary

Hyperplane
The separating boundary w · x + b = 0: a line in 2-D, a plane in 3-D.
Weight vector w
Perpendicular to the hyperplane; sets its direction and points to the +1 side.
Bias b
Shifts the hyperplane away from the origin.
Margin
The gap between the nearest points of the two classes, 2/‖w‖.
Support vectors
Training points on the margin lines, yᵢ(w · xᵢ + b) = 1. They alone define the boundary.
Optimal hyperplane
The separator with the maximum margin: minimise ½‖w‖² subject to yᵢ(w · xᵢ + b) ≥ 1.
Soft margin, C
Slack ξᵢ allows violations; C is the penalty per violation. Large C: narrow margin. Small C: wide margin.
Kernel
K(xᵢ, xⱼ) = φ(xᵢ) · φ(xⱼ): a dot product in a higher-dimensional space, computed without building φ.
Decision function
f(x) = sign(Σ αᵢ yᵢ K(xᵢ, x) + b), summed over support vectors.

To draw the SVM diagram in an exam: axes x₁, x₂ with two groups of points; the solid hyperplane in the gap; dashed lines w · x + b = ±1 through the nearest points; the support vectors circled; the margin 2/‖w‖ and the vector w marked.
